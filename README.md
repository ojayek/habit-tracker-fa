## ✨ چرا این پروژه؟

- 🗓️ **تقویم شمسی کامل** — بدون نیاز به پکیج خارجی
- 🎨 **طراحی Levels** — مینیمال، تاریک، حرفه‌ای
- 📊 **نمودارهای زنده** — سینوسی + ۳ دونات تحلیلی
- 🔗 **لوگوی بلاک‌چین** — برای هر عادت، در ۳ حالت (خالی / نیمه / کامل)
- ⌨️ **پنل کنترل Ctrl+K** — برای مدیریت تمام المان‌های صفحه
- 🎯 **آیکون‌های thesvg** — با fallback کامل
- 🌐 **کاملاً RTL** — راست‌چین با فونت وزیرمتن
